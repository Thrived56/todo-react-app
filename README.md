# To-Do List React App

A responsive To-Do List application built using React.js and React Hooks.

## Technologies Used

- HTML
- CSS
- JavaScript
- React.js
- React Hooks
- Git
- GitHub

## Features

- Add new tasks
- Mark tasks as completed
- Delete tasks
- Responsive user interface

## React Concepts Used

- useState Hook
- Event handling
- Conditional rendering
- List rendering
- State management

## How to Run

```bash
npm install
npm run dev
